# HEAL

Persönliches Gesundheits-Dashboard. Die Daten liegen verschlüsselt in `data.enc.json`, Deployment per GitHub Actions auf GitHub Pages.

- **Web-App / PWA:** https://tinaschickle.github.io/HEAL/ (in Chrome „Zum Startbildschirm hinzufügen“ bzw. „App installieren“).
- **Android-App (APK):** https://github.com/TinaSchickle/HEAL/releases/latest/download/HEAL.apk, gebaut von `.github/workflows/android.yml`.
- Das Passwort wird einmal pro Gerät abgefragt, danach merkt sich das Gerät den Schlüssel.
